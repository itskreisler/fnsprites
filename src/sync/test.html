Qué necesitas de Google Cloud Console

  1. Proyecto nuevo (o usar uno existente) → Google Drive API habilitada.
  2. Pantalla de consentimiento OAuth → External → app name fnsprites-sync, tu email como support y contacto → añade tu cuenta como Test user.
  3. Credenciales → Crear credenciales → OAuth client ID → tipo Web application → Authorized JavaScript origins: http://127.0.0.1:8080, http://localhost:8080 y https://itskreisler.github.io. No necesitas redirect URIs (flujo token GIS).
  4. Copia el Client ID arriba y dale a «Cargar SDK + Conectar».
